## 1. Quais são as principais diferenças entre computação em nuvem e computação on-premise?

Na computação em nuvem os gastos são maleáveis, são calculados de acordo com a necessidade do sistema e podem ser ajustados facilmente. Ela oferece uma flexibilidade nos preços, usando e pagando apenas pelo necessário. 

Já a computação on-premise, ao contrário, necessita de planejamento e construção de uma infraestrutura previa física, o que acarreta em uma dificuldade de manutenção e aumento de escalabilidade tanto vertical quanto horizontal. Ela demanda um planejamento mais estruturado e responsável, haja vista que demandas de mudanças tomam muito tempo.

  

## 2. Cite e explique pelo menos 3 vantagens de se usar computação em nuvem

1- Flexibilidade de infraestrutura : O hardware que se paga pode ser rapidamente modificado, seja para aumento de potência ou diminuição. Não há a necessidade de se preocupar com manutenção de hardware e estado da infraestrutura

 2- Começo facilitado : Utilizando computação em nuvem se tem um começo mais rápido em função da não necessidade de se construir um servidor próprio e se preocupar com compatibilidade e estrutura de hardware, assim como também elimina a necessidade de espaço

 3- Responsabilidades omitidas : Ao utilizar computação em nuvem o usuário não precisa se preocupar com responsabilidades de manutenção de hardware, apenas precisa se preocupar com manutenção de software. Além disso, a depender do sistema de computação em nuvem, ele também oferece diversas ferramentas que também interferem na parte de software como o IAM, que provê módulos de segurança.


## 3. Explique o que eh IaaS, quais as vantagens e cite os principais produtos de computação da AWS, Microsoft e Google

IaaS é um modelo de computação em nuvem no qual o provedor disponibiliza recursos básicos de infraestrutura pela internet, como máquinas virtuais, processamento, armazenamento e redes. O cliente utiliza esses recursos sem precisar comprar e manter fisicamente os servidores e equipamentos.

 As vantagens de se usar um IaaS é que o investimento necessário para iniciar é reduzido, a escalabilidade é melhor monitorada e aumentada, a flexibilidade de poder modificar a infraestrutura de acordo com a necessidade e a manutenção da infraestrutura física não precisa passar pelo cliente. 

 Principais serviços de IaaS do mercado:

 - AWS : Amazon EC2

 - Microsoft Azure : Azure Virtual Machines

 - Google Cloud : Compute Engine  

## 4. Explique o que é PaaS, quais as vantagens e cite os principais produtos de PaaS da AWS, Microsoft e Google

PaaS é um modelo de computação em nuvem no qual o provedor oferece uma plataforma completa para desenvolvimento, execução e gerenciamento de aplicações. O desenvolvedor não precisa se preocupar diretamente com administração da infraestrutura física, servidores e, em grande parte, do sistema operacional. Assim, pode se concentrar principalmente no desenvolvimento da aplicação.

 Vantagens de se utilizar PaaS incluem um ganho na produtividade ( Desenvolvedores focam mais no código ), escalabilidade ( Os recursos são ajustados de acordo com a demanda da aplicação ), menor necessidade de administração e a facilidade de implantação.

 Principais serviços de PaaS no mercado:

 - AWS : AWS Elastic Beanstalk

 - Microsoft : Azure App Service

 - Google : Google App Engine

## 5. Explique o que é SaaS, quais as vantagens e cite os principais produtos de PaaS da AWS, Microsoft e Google

SaaS é um modelo de computação em nuvem no qual o provedor oferece um serviço parcialmente ou completo para ser utilizado a qual resolva algum problema. O usuário não precisa se preocupar com o desenvolvimento, muito menos com a infraestrutura, um serviço SaaS disponibiliza a solução em uma nuvem de modo que seja facilmente acessado

Principais servisos SaaS no mercado: 

- AWS : Amazon QuickSight ( Analise de dados e BI )
- Microsoft : Microsoft 365 ( Aplicacoes de produtividade )
- Google : Google Workspace ( Aplicacoes de produtividade )

## 6. Cite e explique os 4 modelos de computação em nuvem

Os quatros principais modelos de implementação de computação em nuvem são Nuvem Pública, Nuvem Privada, Nuvem Híbrida e Nuvem comunitária

A Nuvem pública é um modelo em que a infraestrutura de computação em nuvem é disponibilizada por um provedor para diversos clientes. Os recursos são compartilhados entre diferentes organizações, embora cada cliente tenha seus próprios ambientes e controles de acesso.

A Nuvem Privada é uma infraestrutura de nuvem dedicada a uma única organização. Ela pode ser mantida pela própria empresa ou administrada por um terceiro. Esse modelo oferece maior controle sobre a infraestrutura e pode ser utilizado quando existem requisitos específicos de segurança, privacidade e conformidade

A Nuvem Híbrida é uma infraestrutura que combina dois ou mais ambientes de nuvem, normalmente uma nuvem privada e uma nuvem pública, permitindo que dados e aplicações sejam utilizados entre esses ambientes

A Nuvem Comunitária é uma infraestrutura compartilhada por várias organizações que possuem interesses ou requisitos em comum, como necessidades relacionadas à segurança, políticas, conformidade ou objetivos específicos.

## 7. Na computação em nuvem os serviços de armazenamento mais comuns são armazenamentos de objetos , armazenamentos em bloco e armazenamentos de arquivos. Explique cada tipo de armazenamento e cite pelo menos um produto de cada tipo para a AWS, Microsoft e Google

O armazenamento de objetos organiza os dados como objetos, que normalmente contém o próprio dado, metadados e um identificador. É adequado para grandes quantidades de dados não estruturados, como imagens, vídeos, documentos, backups e arquivos de dados  

Um exemplo de cada fornecedora eh:

- AWS : Amazon S3 - Simple Storage Service

- Microsoft : Azure Blob Storage

- Google : Cloud Storage

  
O armazenamento em blocos divide os dados em blocos e disponibiliza esses recursos para sistemas como se fossem discos. É muito utilizado por máquinas virtuais e aplicações que precisam de armazenamento com baixa latência e alto desempenho

 Um exemplo de cada fornecedora eh:
 
 - AWS : Amazon Elastic Block Store ( Amazon EBS )

 - Microsoft : Azure Disk Storage

 - Google : Google Persistent Disk

 O armazenamento de arquivos organiza os dados em uma estrutura de arquivos e diretórios. Ele permite que diferentes máquinas ou aplicações acessem os arquivos por meio de um sistema de arquivos compartilhado 

 Um exemplo de cada fornecedora eh:

- AWS : Amazon Elastic File System ( Amazon EFS )

- Microsoft : Azure Files

- Google : Filestore

## 8. Na computação em nuvem, os serviços de banco de dados mais comuns são referentes ao serviço de banco de dados relacional, Banco de dados NoSQL e banco como serviço. Explique cada tipo de banco de dados e cite pelo menos um produto de cada tipo da AWS, Microsoft e Google

Os bancos de dados relacionais organizam informações em tabelas que se relacionam entre si. Normalmente se utiliza a linguagem SQL para realizar operações de consulta e manipulação dos dados

Exemplo de provedoras desses serviços:

- AWS : Amazon RDS

- Microsoft : Azure SQL Database

- Google : Cloud SQL

Os bancos de dados NoSQL são utilizados para armazenar dados que não precisam necessariamente seguir a estrutura rígida de tabelas, eles podem trabalhar em diferentes modelos, chave-valor, colunas ou grafos, sendo usados em aplicações que precisam lidar com um grande volume de dados 

 Exemplo de provedoras desses serviços:

- AWS : Amazon DynamoDB

- Microsoft Azure Cosmos DB

- Google : Cloud Firestore

 DBaaS é um modelo em que o provedor de nuvem disponibiliza um banco de dados como um serviço gerenciado. DEssa forma, tarefas como provisionamento, manutenção, atualizações, backups e, dependendo do servico, escalabilidade são administradas em grande parte pelo provedor  

 Exemplo de provedoras desses serviços:

- AWS : Amazon Aurora

- Microsoft : Azure Database for PostgreSQL

- Google : Cloud SQL  

## 9. Explique o que eh VPC da AWS e a sua importância para criar soluções para serviços baseados na AWS

Virtual Private Cloud é uma rede virtual isolada dentro da infraestrutura da AWS que permite ao usuário criar e controlar um ambiente de rede para seus recursos na nuvem. Por meio de uma VPC é possível

 definir características da rede, como faixas de endereços IP, subredes, tabelas de rotas e regras de controle de acesso. 

Ela é importante pois permite ter um maior controle sobre a comunicação entre os recursos, além de possibilitar a criação de regras para controlar quais recursos podem se comunicar entre si, quais podem ter acesso a internet. Ela é fundamental para criar soluções na AWS pois fornece uma estrutura de rede isolada e configurável, permitindo organizar os recursos de acordo com as necessidades da aplicação
