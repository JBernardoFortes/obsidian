As CPUs modernas incorporam avanços na microarquitetura para aumentar a eficiência. Assinale a alternativa **CORRETA** que indica qual dos seguintes avanços permite que uma CPU execute mais de uma instrução por ciclo de clock em uma única unidade de execução.

a) Branch Prediction (Previsão de Desvio)  
b) Out-of-Order Execution (Execução Fora de Ordem)  
c) Superscalar Architecture (Arquitetura Superescalar)  
d) Hyper-Threading (Simultaneous Multithreading - SMT)  
e) Virtualização de Hardware (VT-x / AMD-V)


Gabarito : C) Superscalar Architecture ( Arquitetura Superescalar )
