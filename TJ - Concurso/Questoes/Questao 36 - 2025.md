Existem diferentes tipos de backup utilizados para garantir a proteção e a recuperação de dados em caso de falhas ou perdas. Sobre os tipos de backup, assinale a alternativa **CORRETA**:

a) O backup completo copia apenas os arquivos que foram modificados desde o último backup, economizando tempo e espaço.  
b) O backup incremental copia todos os dados do sistema, independentemente de alterações anteriores.  
c) O backup diferencial copia somente os arquivos criados ou modificados desde o último backup incremental.  
d) O backup incremental copia apenas os arquivos que foram alterados desde o último backup, seja ele completo ou incremental.  
e) O backup completo é o mais rápido entre todos, pois realiza apenas uma verificação superficial dos arquivos.
